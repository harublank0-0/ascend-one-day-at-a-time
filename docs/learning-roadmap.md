# Engineering Habits

- [ ] Write ADRs for meaningful architectural decisions
- [ ] Document important concepts
- [ ] Write tests before/alongside important business logic
- [ ] Review failure scenarios
- [ ] Measure before optimizing
- [ ] Consider security during design
- [ ] Consider observability during design
- [ ] Understand trade-offs before choosing technology

---

## Definition of Progress

A topic is considered learned when I can:

1. Explain the concept without memorization.
2. Explain why it matters.
3. Implement it.
4. Explain its trade-offs.
5. Identify common failure modes.
6. Recognize when not to use it.
7. Apply the concept to a different system.
