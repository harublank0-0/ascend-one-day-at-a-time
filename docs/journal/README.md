# Engineering Journal

The engineering journal records what I learn while building Ascend.

The journal is different from technical documentation.

## Documentation

Answers:

> What is this and how does it work?

## Architecture Decision Records

Answer:

> Why did we choose this approach?

## Engineering Journal

Answers:

> What did I learn while solving this problem?

---

## Journal Entry Template

Each meaningful learning milestone should create an entry using the following structure:

1. Context
2. What I thought before
3. What I learned
4. Design / approach
5. Alternatives considered
6. Implementation
7. Problems / mistakes
8. Changes to my mental model
9. Engineering lessons
10. Trade-offs
11. Failure scenarios
12. Questions remaining
13. Things to research
14. Review
15. Key takeaways

The journal should focus on meaningful learning rather than becoming a daily diary.

A journal entry is useful when it captures a concept, mistake, architectural insight,
debugging experience, or engineering lesson that is likely to be useful again.
